# Installation & Setup

There are two ways to get started: the **CLI** (recommended — zero config, full project in one command) or **manual installation** for adding the framework to an existing project.

## System Requirements

| Requirement | Minimum | Recommended |
|---|---|---|
| **Node.js** | 18.0.0 | 20.x or 22.x |
| **npm** | 9.0.0 | Latest |
| **TypeScript** | 5.2.0 | 5.2.2+ |

```bash
node --version   # v18.0.0 or higher
npm --version
```

---

## Option 1: CLI (Recommended)

The `@framework/cli` scaffolds a complete, production-ready project in one command — TypeScript config, ESLint, Prettier, Vitest, Docker, and a working User CRUD API included out of the box.

### Install the CLI globally

```bash
npm install -g @framework/cli
```

### Create a new project

```bash
framework create my-api
```

The CLI will scaffold the project and run `npm install` automatically:

```
Creating project my-api...

✅ Project my-api created successfully!

  cd my-api
  cp .env.example .env
  npm run dev
```

### CLI flags

| Flag | Description |
|---|---|
| `--skip-install` | Skip `npm install` (useful offline or in CI) |
| `--package-manager <npm\|pnpm\|yarn>` | Choose your package manager |
| `--path <dir>` | Output to a specific directory |
| `--force` | Overwrite an existing directory |

```bash
# Examples
framework create my-api --package-manager pnpm
framework create my-api --skip-install
framework create my-api --path /projects/work/my-api
```

### What gets generated

```
my-api/
├── .git/                    # git init runs automatically
├── .gitignore
├── .env.example             # PORT, DB_*, JWT_SECRET
├── .prettierrc
├── eslint.config.js         # ESLint v9 flat config
├── tsconfig.json
├── vitest.config.ts
├── README.md
├── Dockerfile               # Multi-stage build
├── docker-compose.yml       # App + PostgreSQL service
├── package.json
└── src/
    ├── main.ts
    ├── config/
    │   ├── app.config.ts
    │   └── database.config.ts
    └── modules/
        ├── users/           # Full CRUD: entity, DTOs, repo, service, controller
        └── health/          # GET /health endpoint
```

### Run with Docker (zero local setup)

```bash
cd my-api
cp .env.example .env         # defaults work out of the box
docker-compose up            # starts app + PostgreSQL
```

### Run locally

```bash
cd my-api
cp .env.example .env         # fill in your DB credentials
npm run dev                  # hot-reloads via tsx
```

## Option 2: Manual Installation

Use this when adding @framework/core to an **existing** project.

### Install packages

```bash
# npm
npm install @framework/core @framework/logger reflect-metadata

# pnpm
pnpm add @framework/core @framework/logger reflect-metadata

# yarn
yarn add @framework/core @framework/logger reflect-metadata
```

Install dev dependencies:

```bash
npm install --save-dev typescript tsx @types/node @types/express
```

### TypeScript configuration

Create `tsconfig.json`:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "declaration": true,
    "sourceMap": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

:::info Required compiler options
`experimentalDecorators` and `emitDecoratorMetadata` must both be `true` — decorators and dependency injection won't work without them.
:::

### package.json scripts

```json
{
  "type": "module",
  "scripts": {
    "dev": "node --loader tsx src/main.ts",
    "build": "tsc --project tsconfig.json",
    "start": "node dist/main.js",
    "test": "vitest",
    "lint": "eslint src"
  }
}
```

### Application entry point

Create `src/main.ts`:

```typescript
import 'reflect-metadata';
import { config } from 'dotenv';
config();
import { Application } from '@framework/core';
import { Logger } from '@framework/logger';

const logger = new Logger('Bootstrap');

async function bootstrap(): Promise<void> {
  const app = new Application({
    port: parseInt(process.env.PORT || '3000', 10),
    host: process.env.HOST || 'localhost',
    corsEnabled: true,
  });

  // Register your modules here
  // await app.registerModule(UserModule);

  await app.start();
  logger.info('Server running on http://localhost:3000');
}

bootstrap().catch(err => {
  console.error('Failed to start', err);
  process.exit(1);
});
```

:::tip import order matters
`reflect-metadata` must be the **first** import, and `dotenv` config must run before any framework imports that read `process.env`.
:::

### Environment configuration

Create `.env.example`:

```bash
PORT=3000
HOST=localhost
CORS_ENABLED=true

# Database (if using TypeORM)
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASS=postgres
DB_NAME=myapp_db

JWT_SECRET=change_me_in_production
NODE_ENV=development
```

## Optional tooling

### Vitest (testing)

```bash
npm install --save-dev vitest
```

Create `vitest.config.ts`:

```typescript
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    globals: true,
    environment: 'node',
    include: ['src/**/*.{test,spec}.ts'],
    coverage: {
      provider: 'v8',
      reporter: ['text', 'lcov'],
    },
  },
});
```

### ESLint v9 (code quality)

```bash
npm install --save-dev eslint @eslint/js @typescript-eslint/parser @typescript-eslint/eslint-plugin
```

Create `eslint.config.js`:

```javascript
import js from '@eslint/js';
import tsParser from '@typescript-eslint/parser';
import tsPlugin from '@typescript-eslint/eslint-plugin';

export default [
  js.configs.recommended,
  {
    files: ['src/**/*.ts'],
    languageOptions: {
      parser: tsParser,
      parserOptions: { project: './tsconfig.json' },
    },
    plugins: { '@typescript-eslint': tsPlugin },
    rules: {
      ...tsPlugin.configs.recommended.rules,
      '@typescript-eslint/no-explicit-any': 'warn',
      '@typescript-eslint/no-unused-vars': ['error', { argsIgnorePattern: '^_' }],
    },
  },
];
```

### Prettier (code formatting)

```bash
npm install --save-dev prettier
```

Create `.prettierrc`:

```json
{
  "semi": true,
  "trailingComma": "all",
  "singleQuote": true,
  "printWidth": 100,
  "tabWidth": 2
}
```

## Verify your installation

Create `src/__tests__/setup.test.ts`:

```typescript
import { describe, it, expect } from 'vitest';
import 'reflect-metadata';
import { Application, Controller, Get } from '@framework/core';

@Controller('/test')
class TestController {
  @Get('/health')
  health(_req: any, res: any): void {
    res.status(200).json({ status: 'ok' });
  }
}

describe('Installation', () => {
  it('creates an Application instance', () => {
    const app = new Application({ port: 3001 });
    expect(app).toBeDefined();
  });

  it('applies controller decorator metadata', () => {
    const metadata = Reflect.getMetadata('controller:metadata', TestController);
    expect(metadata).toBeDefined();
  });
});
```

Run it:

```bash
npm test
```

Both tests should pass. If the decorator test fails, check that `experimentalDecorators` and `emitDecoratorMetadata` are enabled in `tsconfig.json`.

## Troubleshooting

### `Cannot use import statement` error

Your project `package.json` must have `"type": "module"`.

### Decorator errors at runtime

Both flags must be set in `tsconfig.json`:
```json
{ "experimentalDecorators": true, "emitDecoratorMetadata": true }
```

### `Reflect.metadata is not a function`

`reflect-metadata` must be the first import in `main.ts`:
```typescript
import 'reflect-metadata'; // ← must be first
```

### Port already in use

```bash
# Find what's using the port
lsof -i :3000
# Then either kill the process or change your PORT env var
```

### Module resolution errors with `.js` extensions

With `"module": "NodeNext"`, imports in TypeScript source must use `.js` extensions even for `.ts` files:
```typescript
import { UserService } from './user.service.js'; // correct
import { UserService } from './user.service';     // will fail at runtime
```
